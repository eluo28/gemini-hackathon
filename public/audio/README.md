# Soundboard audio

`mlg-airhorn.mp3` is the recorded MLG airhorn, downloaded from the
[MLG AIR HORN sound page](https://www.myinstants.com/en/instant/mlg-air-horn/).
Source file: https://www.myinstants.com/media/sounds/mlg-airhorn.mp3

The MP3 is served locally and decoded into the soundboard audio mixer, so it
uses the same volume, Stop, stream routing, and recording path as other effects.
